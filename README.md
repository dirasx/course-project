# Курсовая

`$kursovaya` — скилл для работы над технической курсовой в Codex. Он помогает начать новый проект или продолжить существующий: вести план и решения, проверять исходные данные, распределять работу по главам и собирать записку и чертежи.

## Установка

1. Скачайте `kursovaya.zip` со страницы [релизов](../../releases).
2. Распакуйте папку `kursovaya` в `~/.agents/skills/`. Итоговый путь: `~/.agents/skills/kursovaya/SKILL.md`.
3. Откройте проект курсовой в Codex и напишите: «Используй `$kursovaya` и подготовь рабочую структуру по заданию». Если скилл не появился в списке, перезапустите Codex.

В [SKILL.md](SKILL.md) находится рабочий процесс, в [assets/AGENTS.md](assets/AGENTS.md) — шаблон правил для проекта курсовой.
