# Ideas for AutoCAD skills

These ideas need evaluation with sample drawings and a Windows AutoCAD session.

- **Plot review.** Check PDF sheet size, scale, clipping, lineweights and readable labels against the saved DWG and its plot settings. Background reading: [AutoCAD MCP plot workflow](https://github.com/lucasqdn/autocad-mcp).
- **Drawing text and block attributes.** Compare titles, marks and block attributes across sheets and flag inconsistent references. Background reading: [dwg-mcp](https://github.com/bimwright/dwg-mcp).
- **Visual comparison.** Align a rendered sheet with a reference using control points and highlight differences for review. [compare_redraw.py](https://github.com/pengxiaoan/autocad-dwg-redraw-skill/blob/main/skills/autocad-image-redraw/scripts/compare_redraw.py) reports pixel differences, so dimensions still need CAD measurements.

## Идеи для скиллов AutoCAD

- **Проверка печати.** Сверять формат и масштаб PDF, обрезку, толщину линий и читаемость с сохранённым DWG и настройками печати. [Пример работы с печатью](https://github.com/lucasqdn/autocad-mcp).
- **Текст и атрибуты блоков.** Сопоставлять названия, марки и атрибуты на листах и отмечать несогласованные ссылки. [dwg-mcp](https://github.com/bimwright/dwg-mcp).
- **Визуальное сравнение.** Совмещать лист с образцом по опорным точкам и показывать отличия для проверки. [compare_redraw.py](https://github.com/pengxiaoan/autocad-dwg-redraw-skill/blob/main/skills/autocad-image-redraw/scripts/compare_redraw.py) измеряет расхождения в пикселях, а размеры нужно проверять в CAD.

Для оценки этих идей нужны тестовые чертежи и AutoCAD на Windows.
